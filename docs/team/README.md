# Reguły zespołu HubMI

Źródło prawdy dla konwencji. Cursor czyta skróty z `.cursor/rules/`; tu trzymamy pełniejszy, uzupełnialny kontekst.

## Jak uzupełniać

1. Wypełnij sekcje oznaczone `[UZUPEŁNIJ]`.
2. Preferuj krótkie bullet pointy i przykłady „rób / nie rób”.
3. Po istotnej zmianie zaktualizuj odpowiadający plik w `.cursor/rules/`.
4. Unikaj duplikowania całego README — tu tylko decyzje zespołu.
